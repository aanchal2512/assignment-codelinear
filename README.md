# Assignment – CodeLinear Landing Page

A pixel-perfect, fully responsive landing page built as part of the SDE – Full Stack assignment.

## Live Demo

[https://assignment-codelinear-five.vercel.app/](https://assignment-codelinear-five.vercel.app/)

## Tech Stack

- **Next.js** (v16)
- **React.js** (v19)
- **CSS Modules**

## Features

- Fully responsive across desktop, tablet, and mobile
- Reusable component-based architecture
- Clean folder structure
- Smooth UI interactions

## Project Structure

```
src/
├── app/
│   ├── layout.js
│   ├── page.js
│   └── globals.css
├── assets/        # Images and static assets
└── components/    # All reusable UI components
```

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build for Production

```bash
npm run build
npm start
```
